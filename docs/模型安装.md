# 模型安装

推荐 Windows 10/11、64 位 Python 3.12，以及支持 CUDA 的 NVIDIA 显卡。角色模式使用 PyTorch 2.9.1 + CUDA 12.8 预编译环境，不需单独安装 CUDA 开发工具包，但需要兼容驱动。模型安装脚本接受 Python 3.11/3.12。

曾验证 RTX 5060 Laptop 8 GB。游戏与模型会共享显存和算力，请按本机情况评估。完整安装建议预留至少 15 GB 空间。

## 安装

双击根目录“安装角色配音模型.bat”，自动安装应用依赖、独立模型环境，检查 GPU，下载模型并生成本机配置。也可先用“安装基础环境.bat”安装系统中文朗读模式。

模型来自 [Qwen 官方仓库](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-Base)，固定版本 `5d83992436eae1d760afd27aff78a71d676296fc`。下载器支持续传，并检查文件大小及上游 SHA256/Git 哈希。

默认网络较慢时，在发布包根目录打开 PowerShell：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1 -WithModel -ModelScope
```

此选项允许 Qwen 的 ModelScope 镜像作为备用，仍按固定 Hugging Face 版本校验；初次校验信息仍需从 Hugging Face 获取。

没有自动找到 Python 时指定实际位置（下面为示例）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1 -WithModel -PythonPath 'C:\Python312\python.exe'
```

网络恢复后可以重试安装。配置只在依赖、GPU 和模型校验成功后切换到 Qwen 模式。

## 运行

使用根目录“启动AI配音.bat”。服务从 `wuwa-dubber/data/config.json` 读取本机令牌，仅监听 `127.0.0.1:9882`。关闭窗口后模型可能继续运行，不用时点击“停止本地模型.bat”。启停脚本只处理本目录的模型进程。

单独管理模型：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\local-voice-model\scripts\start-server.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\local-voice-model\scripts\stop-server.ps1
```

模型、环境、日志分别位于 `local-voice-model/models`、`.venv`、`logs`。相对模型路径保存于 `wuwa-dubber/data/model_runtime.json`。

## 依赖与复现

`requirements.txt` 是安装使用的固定关键依赖；`requirements-lock.txt` 是原验证环境的完整快照，可用于精确排错和复现。在已创建的模型环境中运行：

```powershell
.\local-voice-model\.venv\Scripts\python.exe -m pip install --extra-index-url https://download.pytorch.org/whl/cu128 -r .\local-voice-model\requirements-lock.txt
```

默认采用 BF16、SDPA、固定随机种子 42、单个生成任务，支持参考提示缓存、取消和超时。模型加载和推理使用本地离线文件。非致命的 SoX/FlashAttention 提示不代表安装失败。

v0.5.0 沿用相同模型版本和依赖，无需为本次优化重新下载模型。存在有效参考声线时自动后台预热；首次空白声线库会跳过预热，导入后可正常生成。FP16、TF32 和编译实验未成为默认设置，原因与实测见 [延迟优化记录](延迟优化.md)。
