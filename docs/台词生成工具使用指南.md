# 台词生成工具 v0.4.3 使用指南

适用 Windows 10/11、64 位 Python 3.12。先生成完整台词音频，再识别游戏字幕播放；播放已有项目音频不需要加载语音模型。

## 首次安装

1. 在 [发布页](https://github.com/emt-faze/-/releases/tag/dialogue-generator-v0.4.3) 下载 `windows-with-ocr-models.zip` 并完整解压到可写目录，例如 `D:\Dubbing`。请使用简短路径，过深的目录可能触发 Windows 的路径长度限制；预留至少 15 GB 空间。
2. 安装 [Python 3.12（64 位）](https://www.python.org/downloads/windows/)，勾选 Add python.exe to PATH。
3. 双击根目录 **安装台词生成工具.bat**。依赖仍需联网安装；带 OCR 模型包会直接校验本地四个识别模型。源码包在此步骤下载它们。
4. 双击 **打开台词生成工具.bat**，默认使用系统中文朗读。Windows 需要安装可用的中文语音。
5. 需要角色声音时，再运行 **安装角色配音模型.bat**。它会创建独立的模型环境、检查 NVIDIA CUDA 显卡并下载约 2.52 GB 的 Qwen3-TTS 权重。
6. 在生成工具点击 **添加角色声线…**，选择单人参考音频或录屏，截取 3–30 秒的完整句子并填写对应文字。末尾建议保留约 0.3 秒停顿。
7. 关闭生成工具和配音设置窗口，双击 **设置默认角色声线.bat**，选择已经导入的声线。默认声线用于角色没有对应绑定时的回退；首次空白声线库需要这一步。已有默认声线无需重设。
8. 重新打开生成工具，选择 **已有角色声线（本地模型）**。安装模型不会自动更改当前项目的生成方式。

角色克隆曾在 RTX 5060 Laptop 8 GB 上使用，其他设备的可用性和耗时需要实测。添加参考片段所需的 FFmpeg 由模型安装步骤提供。模型加载、首次合成仍需要等待；本工具通过提前生成音频降低游戏内播放等待。

## 采集、生成与自动播放

1. 点击 **识别游戏台词…**，选择游戏窗口并分别框选正文和角色名区域。安装包未绑定个人游戏路径，首次需要校准。
2. 采集后停止并返回列表。也可导入 `dialogue.jsonl` / `revisions.jsonl`，或使用 **手动添加台词…**。
3. 核对台词、人物和声线；待复核条目需人工确认。只有省略号等标点的台词保留记录，但不生成语音。
4. 勾选条目，点击 **生成 / 继续勾选项**。生成时不自动播放；完成后可 **试听当前行** 或 **停止试听**。
5. 点击 **自动识别并播放…**，选择游戏窗口并开始。只匹配当前项目中已经完成、核对且仍有效的音频，缺少音频时提示，不临时合成。

主窗口、采集窗口和自动播放窗口可一起最小化并恢复，后台工作继续。游戏本身仍须保持可采集状态。真正切换或消失的字幕会打断上一句；同一句持续显示只播一次。可暂停、跳过和重播。遇到游戏原配音时可手动暂停工具。

批量删除可撤销；删除台词不直接删除原始识别记录与参考录音。取消生成保留已经完成的音频，重试失败项不重做成功项。完整操作细节见 [工具内附说明](../nte-dialogue-ocr/台词生成工具使用说明.txt)。

## 文件与迁移

| 内容 | 本发布包中的位置 |
| --- | --- |
| 项目、逐句音频与清单 | `nte-dialogue-ocr/generation-projects/` |
| 最近项目状态 | `nte-dialogue-ocr/generator-state.json` |
| OCR 记录和图片 | `nte-dialogue-ocr/records/` |
| 窗口及识别区域设置 | `nte-dialogue-ocr/config.json` |
| 声线、参考片段与整句/分段缓存 | `wuwa-dubber/data/profiles/`、`wuwa-dubber/data/cache/` |
| 配音设置与模型位置 | `wuwa-dubber/data/config.json`、`model_runtime.json` |
| 本地模型权重 | `local-voice-model/models/` |

升级前退出识别、生成和播放，备份以上个人数据。推荐在新目录安装后复制个人数据，不覆盖备份。公开包为空白声线库，不包含本机录屏、角色录音、项目和生成音频。

旧桌面布局的 `配音补全/自动流程` 对应新包的 `nte-dialogue-ocr`，旧 `配音补全/data` 对应 `wuwa-dubber/data`。复制项目时整目录复制，保留项目内音频的相对位置。旧记录的原图路径可能仍指向原目录，核验迁移成功前请保留原目录。

移入旧 OCR 配置后，检查 `dubbing.code_root` 为 `../wuwa-dubber`、`dubbing.data_root` 为 `../wuwa-dubber/data`；这两个路径相对于 `nte-dialogue-ocr`。本发布包的 `model_runtime.json` 中 `model_root` 相对于 `wuwa-dubber`，推荐 `../local-voice-model`；原有绝对路径也可用。

跨电脑迁移应重新安装环境，不能复制 `.venv` 代替安装。FFmpeg 绝对路径随电脑变化时重新运行模型安装脚本更新配置；模型文件校验通过后复用。安装脚本保留已有设置，必要修改前备份，不会清空声线、项目或缓存。

## 开发与核验

安装后可运行：

```powershell
.\nte-dialogue-ocr\.venv\Scripts\python.exe -m unittest discover -s nte-dialogue-ocr -p "test_*.py"
.\nte-dialogue-ocr\.venv\Scripts\python.exe -m unittest discover -s scripts -p "test_*.py"
.\nte-dialogue-ocr\.venv\Scripts\python.exe scripts\build_generator_release.py --output dist
```

增加 `--models-dir nte-dialogue-ocr\assets\ocr-v6` 可同时构建带 OCR 模型包。每个包内有逐文件 SHA-256 清单，旁边的 `SHA256SUMS.txt` 用于核对压缩包。私有游戏取样没有公开，对应回归会明确跳过；不能把这些跳过项视为已测试。验收边界见 [验证记录](台词生成工具验证记录.md)。
