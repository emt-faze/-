# 开发说明

应用源码位于 `wuwa-dubber/src/wuwa_dubber`。`SpeechCache` 负责磁盘缓存与原子写入，`split_for_speech` 按自然停顿分段，`SpeechSession` 协调串行生成、顺序播放和最多一段预生成。文字试听与游戏配音使用同一套调度和缓存。

模型服务位于 `local-voice-model/qwen_server.py`，提供 `/v1/health`、`/v1/synthesize` 和 `/v1/cancel`。每次只有一个生成任务，限制请求文本和参考录音长度，取消及超时不返回未完成音频。

## 测试

在发布包根目录运行；应用依赖应已安装。核心测试采用随附轻量运行器，不要求安装 pytest：

```powershell
.\wuwa-dubber\.venv\Scripts\python.exe .\wuwa-dubber\scripts\run_tests.py
$env:PYTHONPATH = (Resolve-Path .\wuwa-dubber\src).Path
.\wuwa-dubber\.venv\Scripts\python.exe .\wuwa-dubber\tests\ui_speech_preview_smoke.py
.\wuwa-dubber\.venv\Scripts\python.exe .\wuwa-dubber\tests\ui_qwen3_smoke.py
.\wuwa-dubber\.venv\Scripts\python.exe .\local-voice-model\test_server_protocol.py
.\wuwa-dubber\.venv\Scripts\python.exe .\scripts\test_release_setup.py
```

这些检查不加载大模型，也不启动游戏。界面测试使用离屏窗口与测试音频。

## 打包

```powershell
python .\scripts\build_release.py
```

结果位于 `releases`，包括 ZIP 和 SHA256SUMS.txt。ZIP 自带 FILE_MANIFEST.json，记录每个文件的大小和 SHA256。打包器只选择源码、测试、入口和说明，避免把 data、运行环境、模型、录屏、参考声音和日志放进包里。

Windows 批处理使用 CRLF、UTF-8；含中文的 PowerShell 脚本使用 UTF-8 BOM，以兼容 Windows PowerShell 5.1。

初次配置产生随机本机令牌，不在仓库保存实际配置。模型运行路径相对于应用目录。若用户设置损坏，安装脚本会停止而非直接覆盖；修改有效设置前保留备份。
