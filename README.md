# 游戏字幕 AI 配音工具

> **独立文字识别工具**：[异环对话 OCR v5.0.0](https://github.com/emt-faze/-/tree/main/nte-dialogue-ocr) · [下载带模型包与源码包](https://github.com/emt-faze/-/releases/tag/nte-ocr-v5.0.0)。默认 WGC，RapidOCR small 首次识别、medium 复核；安装与配置独立于下方配音工具。

为解决二游中支线剧情没有配音、影响游戏体验的问题而制作的探索性工具。读取游戏画面中的角色名和字幕，在本机生成并播放语音。目前以异环的使用流程整理，窗口和字幕区域可自行设置。

**v0.5.0 · 延迟优化版 · 2026-10-31**

- **整句缓存 + 自然分段**：相同文字、声线和生成设置复用已有音频；新台词按句子和自然停顿拆分。
- **首段短切与可调预取**：角色模式默认首段 10 字、后续 36 字，播放时最多提前准备 2 段；支持暂停、重播、跳句和取消。
- **后台模型预热**：有效声线可用时自动预热，用户请求优先；参考编码缓存容量增至 16 组。
- **可检查的耗时**：模型服务记录各阶段耗时；字幕确认默认改为连续 2 帧。
- **两种配音方式**：Windows 系统中文朗读；Qwen3-TTS 本地角色声音克隆。
- **本地字幕识别**：直接捕获游戏窗口，或使用 OBS 虚拟摄像头；角色名匹配声线及别名。
- **文字试听**：无需开游戏即可试听，支持主动重新生成。

新台词仍可能等待数秒到几十秒，分段之间也可能停顿。目前未完成游戏内连续运行验证，不能保证实时跟随剧情。

## 下载和首次安装

**[下载 v0.5.0 发布包](https://github.com/emt-faze/-/raw/refs/heads/main/releases/game-dubbing-v0.5.0.zip)** · [SHA256 校验](releases/SHA256SUMS.txt) · [从旧版升级](docs/使用指南.md#原目录升级到-v050)

也可使用仓库的 **Code → Download ZIP**。解压到普通可写目录，再运行文件夹里的入口。此发布包包含源码和安装脚本，首次安装需要联网下载依赖；不包含 Python、运行环境和约 2.52 GB 的模型权重。

1. 安装 **64 位 Python 3.12**，安装时勾选 **Add python.exe to PATH**。Python 3.11 也可用于模型环境。
2. 双击 **`安装基础环境.bat`**，安装界面、识别和播放依赖。
3. 双击 **`启动AI配音.bat`**。首次默认使用系统中文朗读；在“实时配音”页输入短句，点击“试听这句话”。系统需要有可用的中文语音。
4. 若需要角色声音克隆，再双击 **`安装角色配音模型.bat`**。它会安装本地模型环境、校验 NVIDIA GPU、下载固定版本模型并设置程序。
5. 在“声线与音频”中导入 **3–30 秒单人参考录音**及其准确文字，再选择声线试听。

角色克隆安装需要支持 CUDA 的 NVIDIA 显卡及相应驱动。本项目曾在 RTX 5060 Laptop 8 GB 上运行；其他显卡的速度和可用显存需要实测。建议为完整安装预留至少 15 GB 磁盘空间。

发布包使用空白声线库。游戏角色录音、个人配置、生成音频及本机会话日志保留在原电脑，不随发布包提供。已有用户可按 [迁移与备份说明](docs/使用指南.md#迁移和备份) 保留自己的声线和缓存。

| 根目录中的入口 | 用途 |
| --- | --- |
| `安装基础环境.bat` | 安装识别、界面和系统朗读环境 |
| `安装角色配音模型.bat` | 安装 Qwen3-TTS 并切换到角色克隆模式 |
| `启动AI配音.bat` | 按保存的模式启动；Qwen 模式先启动模型 |
| `打开设置.bat` | 直接打开界面，方便调整配音模式 |
| `停止本地模型.bat` | 停止本目录的模型服务，释放资源 |

首次安装失败时保留窗口中的错误信息，网络恢复后可重新运行。模型下载支持续传和哈希校验。详细配置见 [模型安装说明](docs/模型安装.md)。

## 在游戏中使用

1. 进入能看见台词的游戏画面。
2. 打开“捕获与识别”，选择游戏窗口，分别框选对白和角色名区域。
3. 点击“单帧 OCR 测试”，核对文字和角色名。
4. 回到“实时配音”，点击“启动”。

**F8** 暂停/继续，**F9** 重播，**F10** 跳到最新。快捷键不可用时使用窗口按钮。遇到游戏已有配音的段落，请手动暂停补配音；程序目前不自动区分原配音。

## 缓存和等待时间

试听与实时配音共用 `wuwa-dubber/data/cache`，重启后仍可复用。完整台词缓存、全部可用的旧版分段缓存优先。角色新台词默认首段不超过 10 字、后续不超过 36 字，优先自然停顿，无停顿时按长度拆分；不使用逐字拼接。首段设为 0 可恢复原自然分段策略。

| 操作 | 缓存行为 |
| --- | --- |
| 同一声线重复播放相同文字 | 复用相同生成设置对应的音频 |
| 更换模型、参考录音/文字或语速 | 使用新的缓存 |
| 调整音量、角色别名或令牌 | 可继续复用原缓存 |
| “重新生成并试听” | 更新台词各段；失败段保留原音频 |

Qwen 模式需要服务在线确认模型身份，即使命中缓存也请通过启动入口打开。本机三次测试中，首段短切让 19 字台词的开头就绪中位数从 **21.39 秒降至 10.77 秒**；已有缓存升级前后均约 **0.062 秒**。全新 9 字短句最终仍约 **9.51 秒**，增加预取没有证实能缩短段间停顿。

这些是本地合成和按音频时长模拟播放的结果，不是游戏内端到端延迟或其他电脑的速度保证。**首段 1.5 秒、段间 0.3 秒的目标尚未达到。** 见 [逐项优化结果](docs/延迟优化.md) 与 [验证记录](docs/验证记录.md)。
