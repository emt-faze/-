## 快速开始

1. 安装 **Python 3.12（64 位）**，勾选 Add python.exe to PATH。
2. 完整解压下载包，双击 **安装台词生成工具.bat**。
3. 双击 **打开台词生成工具.bat**。系统中文声模式可先进行手动添加、批量生成和试听。
4. 需要角色声音时，运行 **安装角色配音模型.bat**，然后在工具内 **添加角色声线…**。首次导入后，关闭工具并运行 **设置默认角色声线.bat**，再重新打开并选择角色模式。
5. 点击 **识别游戏台词…**，选择游戏窗口并框选正文与角色名区域；核对台词后生成音频。
6. 点击 **自动识别并播放…**。当前项目中已生成且有效的音频会随游戏字幕播放，切句后停止旧音频。

首次使用需校准游戏区域。系统模式要求 Windows 有中文朗读声音；角色模型要求支持 CUDA 的 NVIDIA 显卡和驱动，建议完整安装预留至少 15 GB 空间。自动播放已准备好的音频不需要加载 TTS 模型。

## 本版功能与修复

- OCR 采集与旧记录导入，手动添加、编辑、删除和撤销删除台词。
- 导入音频或录屏中的角色参考片段，支持角色名、别名和系统声线配置。
- 批量生成、整句缓存、自然分段、停止、失败重试和逐句试听。
- 自动识别字幕并播放当前项目的完整音频，支持切句中断、暂停、跳过与重播。
- 主窗口与采集/播放窗口联动最小化，后台工作继续。
- 修复参考片段末尾残音混入新配音开头、标点前发音截断，以及背景文字和继续图标造成的误判。
- 修复明音凛长句在背景切换后从“已复核”变成“待复核”并停止播放的问题。

自动播放只使用提前完成的项目音频；未生成、缺字或无法明确匹配时会提示。游戏已有原配音时可手动暂停。不同机器、游戏设置与字幕布局仍需自行校准，模型新台词的生成速度与硬件有关。
