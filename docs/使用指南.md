# 使用指南

## 先完成文字试听

安装基础环境后打开程序，默认使用系统中文朗读。在“实时配音”输入短句，点击“试听这句话”。若系统没有中文声音，请在 Windows 语言和语音设置中安装中文语音组件。

安装角色模型后进入“声线与音频”，添加角色名、别名、3–30 秒参考录音及其准确文字。录音应为单人讲话，尽量减少音乐、音效和混响。选择声线后返回“实时配音”试听。

普通试听复用缓存，“重新生成并试听”逐段重新生成。服务使用固定随机种子，相同设置重新生成也可能得到相近或相同结果。更换参考录音后会使用新缓存，无需清空全部音频。

未知角色使用配置的旁白档案。角色模式下请先导入一个通用声线并指定为旁白，避免没有回退声线。

## 校准字幕

进入有字幕的游戏场景，在“捕获与识别”中选择游戏窗口，分别框选对白和角色名，先通过“单帧 OCR 测试”核对再启动。改变窗口大小、分辨率或 OBS 裁切后重新框选。直接捕获窗口无需 OBS。

## 播放与取消

F8 暂停/继续，F9 重播，F10 跳到最新。快捷键不可用时用窗口按钮。暂停、跳句或取消试听会放弃余下待播片段，已经成功保存的缓存仍保留。显示“正在停止”时等待任务收尾，再开始下一次试听。

游戏已有原配音时请手动暂停。新台词仍受模型速度限制，分段之间可能有停顿。需要更快读字幕时切换系统中文朗读并保存，再重新启动程序。

## 迁移和备份

发布包使用空白声线库。原用户迁移伊洛伊、娜娜莉等声线时：

1. 关闭旧窗口，先将旧程序的整个 `data` 文件夹单独备份。
2. 将 `profiles` 和 `cache` 复制到新程序的 `wuwa-dubber/data` 下。
3. 若同时复制 `config.json`，需重新选择窗口、字幕区域、音频输出和 FFmpeg 路径。
4. 不要迁移旧 `.venv` 和 `model_runtime.json`，在新目录重新运行安装入口。
5. 安装完成后在界面选择旁白和角色声线，再做试听。

安装配置修改现有设置前会备份到 `wuwa-dubber/backups`，不会清空声线和缓存。Python 环境不保证可搬家，移动安装位置后应重建环境并重新配置。

## 排错

- 模型连接失败：从“启动AI配音.bat”重新打开，查看 `local-voice-model/logs`。修改令牌后先停止旧服务再启动。
- 只想改设置：使用“打开设置.bat”。
- 导入录音缺少 FFmpeg：角色模型安装会提供 FFmpeg，也可自行安装后在界面指定。
- 没有声音：检查输出设备、音量和系统音量混合器，关闭“测试音模式”，先做单句试听。
- OCR 错误：重新框选字幕区域并执行单帧测试。
- 声音不够像：检查参考录音纯净度、单人说话和准确文字；当前没有统一的音色相似度评估。

“诊断”页可打开数据和日志。分享日志前移除个人信息及令牌。
