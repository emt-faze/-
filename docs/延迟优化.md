# v0.5.0 延迟优化与实测

测量日期：2026-10-30；发布整理：2026-10-31。模型为固定版本 Qwen3-TTS-12Hz-0.6B-Base，RTX 5060 Laptop 8 GB，伊洛伊参考声线。参考录音和生成音频未随仓库发布；可核对的阶段值与逐轮数字见 [测量数据](latency-benchmarks.json)。

## 已完成的改动

| 步骤 | 实现 | 结果 |
| --- | --- | --- |
| P0 阶段计时 | 上下文计时、GPU 同步、诊断 JSON 与日志 | 确认主要瓶颈在推理 |
| P1 预热 | HTTP 端口绑定后后台预热两次，用户请求优先 | 将部分首次开销提前，不证明热态吞吐增加 |
| P2 首段短切 | 首段 10 字、后续 36 字，可配置，首段 0 可关闭 | 较长台词更早开口 |
| P3 参考缓存 | 原内容摘要键保持，LRU 从 8 增至 16 | 最终命中中位数约 1.494 毫秒 |
| P4 预取 | 默认 2，可选 1–3，内存不足降为 1 并重试一次 | 本机未证实段间停顿改善 |
| P5 推理参数 | BF16/TF32/FP16、编译预检查、生成上限对比 | 正式保留原 BF16、SDPA 和 1024 上限 |
| P6 OCR | 新配置默认连续 2 帧 | 5 fps 连续正确识别时少等待约 0.2 秒 |

没有替换模型、降低采样率、逐字拼接、引入多个模型进程或增加在线核心依赖。

## 首段与段间延迟

按 WAV 时长进行无声播放计时，调整前后各 3 次取中位数。

| 文本与指标 | 调整前 | 调整后 |
| --- | ---: | ---: |
| “今天的天气很不错，我们一起出去走走吧。”首段就绪 | 21.391 秒 | 10.766 秒 |
| 同一台词完成模拟播放 | 25.235 秒 | 20.875 秒 |
| 三句台词、预取 1 → 2，每轮最大段间停顿 | 6.750 秒 | 6.969 秒 |
| 同一三句台词完成模拟播放 | 28.532 秒 | 27.141 秒 |

首段短切约提前 49.7%，但三轮短切后的段间等待仍约 6.25–8.14 秒。预取没有测出停顿改善；总时长的差值伴随推理速度波动，不能归因于缓冲增加。

三句文本为“今天的天气很不错。我们一起出去走走吧。路上小心。”。模型生成仍慢于播放，缓冲不能补足持续生成速度。

## 冷启动与热态

9 字短句“今天的天气很不错。”在最初未预热样本中总用时 17.960 秒，其中参考处理 3.813 秒、推理 13.978 秒。模型已在监听前加载，因此请求中的 model_load 为 0；写 WAV 仅约 2.331 毫秒。

最初三次热态中位数 10.199 秒。专项预热耗时 14.646 秒，预热后第一个真实请求 13.739 秒，三次中位数 12.201 秒；这没有证明热态吞吐增加。预热优先使用最近试听的有效声线，不同角色首次使用仍可能需要参考编码。

最终保留正式参数后的三次短句为 9.510、9.423、9.603 秒，中位数 9.510 秒，输出 2.16 秒音频，WAV 摘要与基线同句一致。不能将跨轮运行波动视为已经验证的推理提速。

## 推理实验与回退

各实验使用同一模型、声线和文本，先预热两次，再生成三次。比较总耗时、音频长度、实际生成单位数与输出摘要。

| 参数 | 耗时中位数 | 输出长度 | 决策 |
| --- | ---: | ---: | --- |
| BF16 | 11.466 秒 | 2.16 秒 | 保留稳定设置 |
| TF32 + cuDNN 调优 | 9.301 秒 | 1.84 秒 | 波形改变，按音频长度折算仅改善约 4.8%，未启用 |
| FP16 | 无有效结果 | 无 | 预热触发 CUDA device-side assert，退回 BF16 |
| torch.compile 预检查 | 35.760 秒后失败 | 无 | 缺少可用 Triton，未启用 |

降低生成上限的单独实验容易受到机器状态影响，因此额外在同一个已预热模型内交替测试 1024 和 128，上限各测 3 次。中位数分别 11.750 与 10.885 秒；六次均实际生成 28 个单位、输出相同。这一条短句的约 7.4% 差异不能保证对所有台词成立，较小上限可能截断长句，正式继续使用 1024。

原代码已经使用 torch.inference_mode()。模型权重、推理身份及采样率未变，原音频缓存可继续匹配。短切会改变语气和停顿，本轮没有人工音质或音色相似度评分。

## 缓存、取消与验收边界

用旧代码与新代码读取相同的原有两段缓存，各 3 次；首段就绪中位数均 0.062 秒，生成调用均为 0，音频文件摘要未改变。

真实模型生成中取消约 0.750 秒收尾，没有迟到播放，没有写入取消音频，随后三次生成均成功。自动化还覆盖暂停、跳句、重播、强制重生成失败保留旧缓存、有限预取、内存回退和持续失败退出。

OCR 固定时序测试中，输入在 0、0.2、0.4 秒到达，3 帧在 0.4 秒确认，2 帧在 0.2 秒确认；单帧错误不会触发。两帧连续同一错误更容易通过，可改回 3。

**首段 ≤1.5 秒、段间 ≤0.3 秒未达标。** 上述为本机合成及模拟播放数据，没有完成实机游戏内连续捕获与音频播放，也没有在其他硬件上重复性能实验。各项发布检查见 [验证记录](验证记录.md)。
